## HTML vs CSS: HTML과 CSS의 역할을 자신의 말로 간단히 정리
- HTML = 기본적인 페이지의 구성 요소 배치 및 contents 를 포함
- CSS = HTML을 기반으로 배치 된 contents의 디자인을 담장
